# 架构决策记录 ADR 索引

本目录记录 dsh-live-token-stats 的架构决策，每篇 ADR 回答「为什么这样选」，含决策、背景理由、被否决选项。变更事实记在 changelog，实现以交付代码为准；ADR 不替代实现。

## 写入标准：三条同时满足才写

1. **难撤销**：改动牵动全局链路，逆转成本高。
2. **无上下文会惊讶**：只看代码仍不明白为何如此选择。
3. **真实权衡**：比较过多个候选方案，存在取舍。

不满足的常规选择，如换库、加参数、常规工程组织，不写 ADR，留 changelog。
